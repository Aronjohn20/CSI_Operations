# CSI Operations

An operational orchestration and event automation platform for the Computer Society of India (CSI) student branch.

---

## 📚 Specification & Architecture Documents

The project follows a modular, specification-first development process:

- **[PROJECT_CONTEXT.md](file:///r:/VSCODE/CSI_Operations/PROJECT_CONTEXT.md)**: Project background, core objectives, and target hosting.
- **[ARCHITECTURE.md](file:///r:/VSCODE/CSI_Operations/ARCHITECTURE.md)**: Complete system flowchart, components, and data flow.
- **[BUSINESS_RULES.md](file:///r:/VSCODE/CSI_Operations/BUSINESS_RULES.md)**: Rules for the 23-member roster, document generation, Bitly links, certificates, and the admin easter egg.
- **[UI_UX_SPEC.md](file:///r:/VSCODE/CSI_Operations/UI_UX_SPEC.md)**: CSI color palette, typography, layout guidelines, and component design tokens.
- **[DATABASE_SPEC.md](file:///r:/VSCODE/CSI_Operations/DATABASE_SPEC.md)**: PostgreSQL / Supabase table schemas and relational DDL.
- **[IMPLEMENTATION_PLAN.md](file:///r:/VSCODE/CSI_Operations/IMPLEMENTATION_PLAN.md)**: Phased feature-by-feature milestone roadmap.
- **[AGENTS.md](file:///r:/VSCODE/CSI_Operations/AGENTS.md)**: Strict operational guidelines for incremental, error-free AI pair programming.

---

## 🚀 Development Workflow
We build **one feature at a time**:
1. Implement single feature according to specification.
2. Test and verify thoroughly.
3. Obtain user confirmation before advancing to the next milestone.
